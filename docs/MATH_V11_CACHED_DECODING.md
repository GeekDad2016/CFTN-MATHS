# V11 cached incremental math decoding

## Why this exists

V11 Stage 5 evaluates procedural long multiplication and exact division with a
2,048-token generation allowance. The former generator re-ran the complete
causal Transformer for every generated byte, in batches of up to eight prompts.
Epoch 125 completed training but failed during generation validation with a
CUDA allocation error inside the Transformer forward pass. No training loss,
dataset, checkpoint, or acceptance gate caused that failure.

## Implementation

`MathTower.begin_cached_generation` performs one full, batch-one prompt
prefill and records each existing transformer's projected attention keys and
values. `MathTower.cached_generation_step` then processes only the newly
generated token and attends to that per-layer cache. The implementation uses
the existing `TransformerEncoderLayer` weights directly, is eval-only, and
adds no parameters. Existing checkpoints remain load-compatible.

`generate_math_tower` uses this cached path whenever the model provides it.
It decodes prompts individually because their prefixes differ in length. This
removes padded multi-prompt long-context generation and changes decoding cost
from repeated full-context forwards to one prefill plus one-token steps.

The existing validation OOM backoff remains a fail-safe for any future model
without cached decoding; it does not change selected records, target answers,
generation allowance, scoring, or acceptance thresholds.

Validation audit rows are flushed after every completed chunk instead of only
after the entire panel. `status.json` reports the active panel, completed and
total examples, elapsed time, EOS completions, context-limit hits, token-budget
hits, effective batch size, and OOM retries. A long or malformed generation is
therefore observable while validation is still running, and partial evidence
survives an infrastructure interruption.

## Verification and operational status

`tests/test_math_capacity.py::test_cached_incremental_math_decoding_matches_full_forward`
compares cached prefill and one-token continuation logits against ordinary full
forwards using the same frozen tower weights. The observed numerical error in
the initial check was below `1e-7`.

V11's last preserved checkpoint is epoch 124. The interrupted epoch-125
attempt is intentionally not a checkpoint. Before resuming, run the focused
test on the local RTX 4070 and then resume from epoch 124; validation should
record cached decoding progress without altering curriculum evidence.
